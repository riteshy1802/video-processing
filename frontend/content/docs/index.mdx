## Platform Overview

**Transcode.io** is a distributed video transcoding and adaptive HLS streaming platform. Upload a video, and the system automatically plans, transcodes, assembles, and delivers multi-resolution adaptive streams — all while you watch progress in real time.

## High-Level Flow

```
Upload
  ↓
Planning       — determine renditions and chunks
  ↓
Transcoding    — parallel FFmpeg workers process chunks
  ↓
Assembly       — rendition playlists assembled
  ↓
Finalization   — master.m3u8 generated
  ↓
Streaming      — HLS.js delivers adaptive stream via CloudFront
```
